# Rede Auto Ribeirão

Plataforma SaaS de gestão para lojas de veículos seminovos.

## 🚀 Tecnologias

- **Frontend**: Vite + React 19 + TypeScript
- **Estilização**: Tailwind CSS v4
- **Backend / Database**: Supabase (Auth, Postgres, Storage, Realtime)
- **Ícones**: Lucide React
- **Roteamento**: React Router DOM v7

## 📦 Instalação e Execução

1. Instale as dependências:
```bash
npm install
```

2. Configure as variáveis de ambiente:
Copie o arquivo `.env.example` para `.env` e preencha suas credenciais do Supabase:
```bash
cp .env.example .env
```

3. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```

4. Para iniciar o servidor WhatsApp:
```bash
npm run wa-server
```
